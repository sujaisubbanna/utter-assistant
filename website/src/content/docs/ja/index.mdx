<div class="utter-strip">
  <div>
    <strong>プッシュトゥトーク</strong>
    <p>アシスタントキーを押しながら話すか、ディクテーションキーを押しながら話せば、開始したフィールドに入力できます(Linux と macOS の両方で動作します)。</p>
  </div>
  <div>
    <strong>デスクトップアクション</strong>
    <p>アプリや Web サイトを開き、ウィンドウをフォーカス・閉じ、ワークスペースを切り替え、メディアを操作し、アプリのショートカットを押します。</p>
  </div>
  <div>
    <strong>ルール優先</strong>
    <p>ほとんどのコマンドは高速で予測可能なルールに一致します。小さなローカルモデルは用意されたアクションの中から選ぶだけです。コマンドを作り出すことはありません。</p>
  </div>
  <div>
    <strong>オフライン</strong>
    <p>音声認識、AI モデル、スクリーンショットはすべてお使いのマシン内に留まります。アカウントもテレメトリもありません。</p>
  </div>
  <div>
    <strong>GPU を解放</strong>
    <p>「go to sleep」と言うか、しばらく使わないでおくとモデルがアンロードされます。キーを押し続ければ一瞬で復帰します。</p>
  </div>
</div>

<CardGrid>
  <Card title="2 つのモード、2 つのキー" icon="seti:audio">
    **アシスタントキー**(既定は Insert)を押しながら話すとコマンドを実行します。**ディクテーションキー**(既定は F13)を押しながら話すと入力します(Linux と macOS の両方で動作します)。各モードには独自のサウンドと波形の色があります。
  </Card>
  <Card title="コンテキストを理解" icon="laptop">
    Utter はどのアプリがフォーカスされ、画面に何があるかを把握します。まずアクセシビリティ情報を使い、最後の手段としてのみスクリーンショットを撮ります。
  </Card>
  <Card title="編集できるアプリ別アクション" icon="pen">
    インストール済みアプリがカタログ化されると 100 以上のアプリプロファイル。ショートカット付きで、設定アプリまたは YAML ファイルから任意のキーの組み合わせを変更できます。
  </Card>
  <Card title="既定で安全" icon="approve-check">
    ターミナルコマンドと生の入力は、有効にするまでオフのままです。重要なアクションは先に確認します。画面のテキストはアクションを選択できますが、作成はできません。
  </Card>
</CardGrid>
