# Security Policy

Utter runs locally and talks to your desktop, so we take security reports seriously.

## Supported versions

Only the **latest release** is supported with security fixes. Please check
[the latest release](https://github.com/sujaisubbanna/utter-assistant/releases/latest) and confirm the
issue still reproduces there before reporting.

## Reporting a vulnerability

**Please do not open a public issue for security problems.**

Report privately through either channel:

- **GitHub Security Advisories** — use the **["Report a vulnerability"](https://github.com/sujaisubbanna/utter-assistant/security/advisories/new)**
  tab on the repository (preferred).
- **Email** — `security@utter.sujaisubbanna.com`.

Please include, as far as you can:

- A description of the issue and its impact.
- Clear reproduction steps or a proof of concept.
- The affected version and platform.
- Any suggested fix or mitigation you have in mind.

## What to expect

This is a small, best-effort project. We aim to acknowledge reports within a few days and will keep
you updated as we investigate and fix. Please give us a reasonable window to release a fix before
disclosing the issue publicly.
